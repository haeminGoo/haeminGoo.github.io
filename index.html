CASE NOTE / DEEP DIVE

지도 서비스를 게임의 무대로 바꾸다

랜드 NFT를 중심으로 사용자가 ORB 토큰을 소비해 주사위를 던지고, 지도 위를 이동하며 보상을 만드는 블록체인 게임입니다. 이후 빌딩 NFT 스테이킹과 로봇 파츠 수집·파밍 등으로 플레이 경험을 확장했습니다.

3초첫 NFT 민팅 매진
약 68만원초기 랜드 민팅가

01 · Challenge
공식 기능이 없는 지도 위 게임

Mapbox가 공식적으로 지원하지 않는 방식으로 외부 지도 위에 3D 건물과 게임 애니메이션을 결합해야 했습니다. 지도 탐색과 실시간 시각 효과가 동시에 동작하면서도 하나의 게임 화면처럼 느껴져야 했습니다.

02 · Execution
지도와 3D, 애니메이션의 결합

Mapbox 지도에 Three.js 기반 건물을 올리고 Canvas 애니메이션을 결합했습니다. MetaMask 지갑 연결부터 NFT·토큰 상태와 게임 흐름까지 프론트엔드 전체를 설계하고 구현했습니다.

03 · Migration
서비스와 사용자 자산의 이동

서비스가 Klaytn에서 Polygon으로 이전할 때 블록체인 연결 전반을 교체하고, 기존 사용자가 자산을 옮길 수 있는 브릿지 화면과 흐름을 구현했습니다.

04 · Collaboration
기획을 구현 가능한 언어로

백엔드 2인, 기획 1인, 디자인 1인과 원격으로 협업했습니다. 기획을 화면과 API 요구사항으로 구체화해 백엔드와 조율하고, 게임 애니메이션은 디자이너와 동작을 함께 다듬었습니다.

Retrospective

다시 만든다면 Three.js와 애니메이션이 동시에 동작하는 구간의 렌더링 부하를 먼저 측정하고, 저사양 환경을 포함한 성능 기준을 설계 초기부터 적용하고 싶습니다.

04 · Partnership

Retrospective

CASE NOTE / DEEP DIVE

지도보다 먼저 발전소 운영을 배우다

한국남동발전이 폐쇄망 안에서 발전기 위치와 실시간 상태를 파악하기 위한 시스템입니다. 완성된 기획 없이 시작해 발전소의 실제 니즈와 인공지능 예측 데이터를 이해하고, 무엇을 어떤 화면으로 보여줄지부터 정의했습니다.

3개월도메인 학습과 고객사 기획 협의
시·군 단위직접 구현한 대한민국 지도 범위
폐쇄망외부 지도·개발·테스트가 제한된 환경
01 · Discovery
도메인 지식부터 제품 요구사항까지

신입 기획자와 함께 대표·이사진, 인공지능 부서의 예측 데이터, 영업부가 수집한 발전소 요구를 연결했습니다. 약 3개월 동안 발전 산업의 언어를 익히고 화면과 기능으로 구체화해 남동발전의 확인을 받았습니다.

02 · Visualization
외부 지도 없이 대한민국을 탐색하다

외부 지도 서비스를 사용할 수 없어 D3와 TopoJSON으로 대한민국 지도를 직접 구성했습니다. 시·군 단위까지 탐색하고 지도 위 발전기 위치와 변화하는 상태 데이터를 함께 파악할 수 있도록 구현했습니다.

03 · Scope
늘어난 기획 일정, 지켜야 하는 오픈 일정

두 달로 예상했던 기획이 세 달로 늘어났지만 오픈 일정은 변경할 수 없었습니다. 핵심 모니터링 기능을 먼저 제공하고 세부 기능은 이후 단계로 분리하는 방향을 고객사 및 팀과 조율했습니다.

04 · Delivery
현장에서만 확인할 수 있는 데이터

폐쇄망으로 들어오는 실시간 데이터는 외부 개발 환경에서 재현하거나 테스트할 수 없었습니다. 현장 출장으로 실제 데이터 연결과 화면 반영을 확인했고, API는 시니어 백엔드 개발자에게 설계를 위임하며 역할을 분담했습니다.

Retrospective

최종 납품 전에 퇴사해 운영 결과까지 확인하지 못한 프로젝트입니다. 다시 진행한다면 폐쇄망과 유사한 로컬 테스트 데이터를 초기에 구축하고, 기획 지연 가능성을 반영한 단계별 출시 범위를 처음부터 합의하겠습니다.
